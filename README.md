## Built to be inherited.

We’re an independent consultancy in Bath. We look after the devices, cloud platforms and web applications that organisations run on.

- **[Endpoint & mobility](https://bath.limited/devices/).** Macs, Windows PCs, iPhones, iPads and Android devices under management, with Jamf Pro, Intune, Apple Business Manager or whatever suits the fleet, and the one-off moves between them.
- **[Cloud & infrastructure](https://bath.limited/cloud/).** Microsoft 365, Azure, Google Workspace and Okta, set up and secured, and the move from the server in the cupboard to whichever cloud suits.
- **[Web & app development](https://bath.limited/websites/).** Websites and web applications, designed and built from the first sketch to the finished thing running live, in Welsh and English where it’s wanted.

We come to you in Bath, Bristol and Cardiff, and work over a shared screen for anyone in the UK.

Client work here is private to the client it was built for. When we finish, we hand all of it over: the code, the accounts, the keys, and the reasons we did it the way we did.
